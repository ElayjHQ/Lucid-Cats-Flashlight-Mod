================================================
  Lucid Cats Flashlight  -  by you + friends :)
================================================

WHAT THIS DOES
  Adds a floating, synced flashlight with a volumetric beam.
  The default bind is F; it can be changed to any keyboard key
  or mouse button in Settings > FLASHLIGHT.
  The battery lasts 40 seconds of continuous use and recharges
  in 60 seconds while off. The optional HUD shows charge level.

HOW TO INSTALL
  1. Make sure Lucid Cats is closed.
  2. Double-click  install.bat
  3. Launch the game through Steam as usual.
  4. In-game, press F (or your configured bind) to toggle it.

REQUIREMENTS
  - Everyone who wants to USE a flashlight needs this mod.
  - Everyone who wants to SEE other players' flashlights needs this mod.
  - The lobby HOST must have the mod for beams to sync at all.
  - Everyone should use the same mod version for reliable sync.
  - Vanilla players can still play normally; they just see no beams.

CONTROLS
  F                    toggle flashlight (default)
  Settings > FLASHLIGHT to change the key or mouse button.
  Or hold the current bind for 2 seconds in-game, then press
  a keyboard key or mouse button. Esc cancels.
  Toggle only works during gameplay, not in menus or the laptop.

TUNING (optional)
  After first launch, edit:
    BepInEx\config\lucidcats.flashlight.cfg
  Change settings in Settings > FLASHLIGHT or edit the config.
  Battery defaults: 40 seconds of light, 60 seconds to recharge.
  For other players' beam position, use RemoteYaw = 180 if
  someone's beam points backwards.

UNINSTALL
  Double-click  uninstall.bat  - the game returns to vanilla.

TROUBLESHOOTING
  - If the game fails to start, run uninstall.bat and check
    BepInEx\LogOutput.log in the game folder for errors.
  - Game updates may temporarily break the mod until it is updated.

Version 1.2.0  -  BepInEx 6.0.0-be.793  -  works with Lucid Cats Unity 6000.3.11f1
