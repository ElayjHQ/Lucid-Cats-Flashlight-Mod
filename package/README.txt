================================================
  Lucid Cats Flashlight  -  by you + friends :)
================================================

WHAT THIS DOES
  Adds a flashlight to the game. Press F in-game to toggle it.
  Everyone in your lobby who has this mod installed can see
  everyone else's flashlight beam.

HOW TO INSTALL
  1. Make sure Lucid Cats is closed.
  2. Double-click  install.bat
  3. Launch the game through Steam as usual.
  4. In-game, press F to toggle your flashlight.

REQUIREMENTS
  - Everyone who wants to USE a flashlight needs this mod.
  - Everyone who wants to SEE other players' flashlights needs this mod.
  - The lobby HOST must have the mod for beams to sync at all.
  - Vanilla players can still play normally; they just see no beams.

CONTROLS
  F      toggle your flashlight
  (Only works during actual gameplay - not in menus or the laptop.)

TUNING (optional)
  After first launch, edit:
    BepInEx\config\lucidcats.flashlight.cfg
  You can change brightness, range, beam width, shadows and
  the beam position for other players (use RemoteYaw = 180 if
  someone's beam points backwards).

UNINSTALL
  Double-click  uninstall.bat  - the game returns to vanilla.

TROUBLESHOOTING
  - If the game fails to start, run uninstall.bat and check
    BepInEx\LogOutput.log in the game folder for errors.
  - Game updates may temporarily break the mod until it is updated.

Version 1.0.0  -  BepInEx 6.0.0-be.793  -  works with Lucid Cats Unity 6000.3.11f1
